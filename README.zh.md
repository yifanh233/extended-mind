# 延展心智（Extended Mind）

一个几乎什么都能帮你做、而且不会从头开始的助手。你只需要说，它会抓住重
点、核实它们，并在你正好需要时把它们带回来。每一次对话都建立在上一次之
上，而不是一关掉窗口就烟消云散。

它会和你一起思考，会反驳而不是奉承；会给自己的猜测标上“未核实”，而不是
把它们当成事实；每当你同意它整理一次，它就会变得更敏锐——把你反复做过的
工作汇编成可复用的技能——还会按照你自己的计划安排你的一天。它不绑定某一
家 AI——任何有能力的助手打开这个文件夹，都能接着上一个助手停下的地方继
续。没有你的签署，任何内容都不会成为永久记忆。而且它没有任何一条行为是
固定不变的：让它新增、改变或删除某个行为，它会在你批准后改写自己的规则
手册。

**先拿到属于你自己的副本。** 点击上方的 **Use this template**——或者克隆本
仓库后删除其中的 `.git` 文件夹。无论哪种方式，你得到的都是一个历史属于
**你自己**的仓库：你的第一次提交，就是这套系统认可的第一份内容，而这个签
名正是整个信任模型的核心。把它放在一个独立的文件夹里，不要放进任何现有项
目。

**然后开一个会话**：用你的编程助手（Claude Code、Codex、Cursor、Gemini
CLI……）在那个文件夹里说一声 `hi`。设置全程在聊天里完成——你不需要打开任
何文件。（可选的开头加速：
先把任何关于你自己或你工作的文件放进 `workspace` 文件夹，助手会主动提出
读取它们。）

四扇门：

1. **我突然有个想法** → 直接说出来，它会替你归档。
2. **我接下来该做什么？** → 直接问；你批准过的日程会回答。
3. **陪我把这件事想清楚** → 直接聊。
4. **把它记住** → 说 `end`，然后粘贴它递给你的两行短提交命令——你的签名。

当某件它能做的事会对你有帮助时，它会用一行字说出来——频率很低，同一件事
最多提醒两次；说 `no tips` 可以关掉。（GUIDE.zh.md 里有“你的第一周”一
节，告诉你该期待什么。）

系统内部的规则文件特意保留英文——AI 助手执行英文指令更可靠，也更省上下
文。你读到的一切、它为你写的一切，都会用你的语言。请不要翻译规则文件；
如果需要中文说明，请阅读本翻译指南。

想了解细节？[GUIDE.zh.md](GUIDE.zh.md) 五分钟就能读完。你的记忆以纯文本
形式存放在这台机器上，任何编辑器都能打开。
