# Load by task

Read this router, then only matching rows and named sections. A link is available
context, not an instruction to open everything it links to. Keep small rule and
permission checks; expand only for the current action.

| when | Situation | Read next |
|---|---|---|
| start | Session start | INDEX Current focus; latest SESSLOG next/threads; agenda/due and pending summaries under rule 2. Full recent blocks only for boot/prior-state work. |
| write | Before writes/resumes | Current LIVE.md; coordination.md when starting/changing activity or ownership is unclear. Reuse unchanged procedures within the session. |
| project | Project task | PROJECT goal, where, constraints, load, open; STATUS for current state. Follow load links only where relevant; skip old log/history unless needed. |
| design | Reasoning/design | Task-scoped rule _router, then matching active procedure/guidelines. Skill _index to find an applicable execution procedure; obey its follow policy. |
| question | Specific question | Search kb for its terms; read matching passages and evidence bearing on the answer. Expand to relevant episodes if needed. |
| parallel | Parallel plans/research | [Research](coordination-reference.md#research). Integration waits until both passes stop. |
| build | Implementation/testing | Relevant source/local instructions; templates §C scope boundaries. One working agent; others pause. |
| proposal | Before presenting a design or a decision request | AGENTS.md rule 8 as written there. |
| system-change | Proposing a system change | Templates §A Simplicity critic, plus only the grammar being changed. |
| rule | Stating, moving or ruling on a rule or a staged lesson | Templates §G before the echo. |
| project-loop | Project resume/decision/handoff | Templates §J: resume 1; material decisions 2–3; checking 4–5; handback 8–9. Steps 6–7 only at their stated triggers. |
| handback | Ending substantive work | Templates §B format/needed fields; [Records](coordination-reference.md#records); §J 8 for project updates. |
| schedule | Schedule mutation | Templates §S, before the action. |
| new-project | Creating a project, or first access to one | Templates §W, before the action, with every step it lists for that case. |
| consolidate | The word pending or consolidate, a review reply, a control word, or a stub printed by submit | Templates §F (and §A for a review); [Consolidation](coordination-reference.md#consolidation); [Ritual](coordination-reference.md#ritual) only for a frozen window. |
| recovery | Interrupted publication/helper error | [Recovery](coordination-reference.md#recovery); source/tests only for diagnosis or changes. |

The `when` ids are the closed list for rule labels (§G); only the user adds a row.

Read the named section, not all of templates.md or a reference file. No full
history, raw evidence bundle, skill body, ritual or recovery procedure loads by
default. Retain them on disk. Follow another matching link if context is missing.
